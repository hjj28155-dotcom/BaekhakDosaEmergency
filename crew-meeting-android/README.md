# 항행의자유 선장·항해사·통제관 공동회의 — Android 독립 시험판
- 패키지: `kr.hanghae.crewmeeting`. 기존 V3 `com.baekhak.dosa.v4` 및 V7 앱과 별개.
- WebView가 기존 `crew-meeting.html` HTTPS 회의 화면만 표시합니다.
- 파일 선택기 연결이 포함되어 있으나 서버의 파일 송수신 기능이 구현·검증되기 전까지 실제 전달 완료를 주장하지 않습니다.
- 기존 ChatGPT 원본 항해사·통제관 대화방을 직접 연결하지 못합니다. 별도 API 역할은 원본 ChatGPT와 다릅니다.
- 서명: 독립 **시험용 debug 인증서**. cache에 저장되는 디버그 서명이며 공식 배포용 키로 취급하지 않습니다.
- 현재 시험판은 V3/V7 저장·승인·누적 기록을 수정하지 않으며 두 앱을 삭제/초기화하지 않습니다.
