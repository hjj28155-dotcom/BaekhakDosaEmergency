# 2026-10-29 KST V8.0.5 각 방 화면 간소화

선장 지시: 각 방에 불필요한 항목이 너무 많음. 핵심 업무를 우선 배치하고 부가 기능은 펼침 메뉴로 이동.

기준 V8.0.4 / code 804, 수정 V8.0.5-SIMPLE-ROOMS / code 805. 같은 package 및 기존 V8 서명 고정 유지.

- 통제실장 방: 원본 대화/보고서/홈 복귀 우선. 주소설정·서버점검·소통·연결진단·중복 소개는 설정·상세로 이동.
- V3 방: 4개 방 결과전 조회와 기존 V3 앱 실행 우선. 반복 설명·방별 같은 연결문구·원본방 바로가기는 연결·상세로 이동. 전송 연결 전 상태는 한 줄 유지.
- V4 분석방: 회차 분석/결과보고서/방별 선택/자료실 유지. 초기화는 추가 기능에 배치.
- 공동 소통방: 공유기록과 입력 중심. 원본방에 자동전송하지 않는다는 상태는 한 줄 유지. 긴 설명·연결 안내 복사·담당자 상태는 연결 안내·상세로 이동.
- 보고서방: V3 파일 미리보기 우선. 과거 V7 기록과 긴 설명은 과거 V7 자료·상세로 이동.

모든 기존 DOM ID/이벤트를 유지한 노드 이동. 원본 기록/DB/잠금/서버/API/인증 저장 무변경. V7 서버 자료 삭제 없음. V3 native 통합/동일서명 V3 APK/단말 인증/실제 자동전송 검증은 기존 미완료 항목으로 유지.

로컬 inline JS 4개 구문검사 통과. CI에서 360/390/412px 펼침 전후 가시성·화면 이동·JS오류·회귀 및 동일서명 APK를 검사. 결과는 확인 후 후속 기록.
