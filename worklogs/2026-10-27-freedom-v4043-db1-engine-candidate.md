# ⚓ 항행의자유 V4.0.43 DB-1 엔진 연결 후보 인계 — 2026-10-27

## 선장 지시
- 중앙통제실은 선장 전용 독립 앱, 일반 배포용이 아님. V3, V33, V7은 각각 별도.
- 항행의자유 승인 완료자의 업데이트/재설치에 재승인 요청 불필요. 신규 사용자의 최초 승인 정책은 유지.
- 일반판 최근 5회차 1243~1247 접근 제한, 저장 조합 표시 복구.
- DB-1 1~1247회차 원문은행은 필수. 현재 원문이 있으면 우선하고, 과거 원문을 함께 분석하여 자동 20조합 생성. 현재 원문 입력이 없을 땐 해당 회차 DB-1 원문을 사용.

## 확인된 기존 문제
- GitHub release/freedom-v4042-version-status-20261026 기준 V4.0.42의 엔진 브리지는 V3_ANALYZE에서 해당 회차 d.raw만 읽고 v13Run()을 실행한다. 과거 DB-1 원문은 엔진에 자동 전달되지 않았음.
- raw_bank.js와 db1_v1247_patch.js에서 1~1247회차 6문장 원문은행을 검증하는 기존 회귀검사 PASS. 핵심은 데이터 부재가 아니라 과거자료 입력 연결 부족.
- 1247회차 원문만 표시하는 분기, 저장 자동20이 없으면 과거 실제 최종5도 숨기는 분기 존재.

## 실제 변경
- 별도 fix/freedom-v4043-repeat-approval-round-combos-20261027 브랜치에만 독립 APK 원본수정 보존. 기존 4.0.42 공개 APK와 중앙통제실 1.0.13 APK는 교체하지 않음.
- V4.0.43 source versionCode=40043. 승인된 기기는 반복 승인확인을 건너뛰고 최초 승인 정책 유지.
- DB-1 1247건/6문장 확인, 수동 현재 원문 우선, 원문이 없으면 DB-1 해당 회차 사용. DB-1 확인 불가 시 가짜 조합 생성하지 않음.
- 현재 입력과 1~선택회차-1 검증 DB-1의 텍스트를 비교하고 최근 1회, 가장 유사한 1회, 중간 시대 1회 총 최대 3회차를 실제 V2 엔진에 차례로 전달. 현재 엔진 후보 가중치 80%, 과거 최대 3회의 엔진 후보 20%, 현재 상위 6수 보존. 이것은 새 연구규칙으로 예측력 향상은 검증되지 않음.
- db1Evidence에 비교 회차, 실제 과거 엔진분석 회차, 적용 가중치, 당첨번호 미사용 상태 기록.
- 과거 추첨완료 회차 재계산은 analysisResearch 사후연구 전용, 실제 RESULT-BEFORE 잠금/구매 기록/성적을 덮어쓰지 않음.
- 일반판 DB 목록 최근5회 제한. 중앙통제실 홈 문구를 선장 전용으로 구분하고 일반판 설치 안내에 승인 완료 사용자 건너뛰기 분기 추가.
