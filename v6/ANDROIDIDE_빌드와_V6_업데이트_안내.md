# 항행의자유 V6 — AndroidIDE 설치 및 업데이트 안내

## 0. 원칙
- V5 앱은 지우지 않습니다. V6는 별도 앱입니다.
- 승인하신 V6 홈 화면(전체방 + 1~5번방) 디자인과 배치를 유지합니다.
- ZIP은 **Android Studio/AndroidIDE용 소스 프로젝트**입니다. APK 파일이 아닙니다.
- 이 프로젝트는 V6 홈 화면을 APK 내부에 포함해 WebView에서 HTML 화면으로 렌더링합니다. 화면 자체는 서버 주소를 직접 열어 표시하지 않으므로 원시 HTML 소스가 보이던 오류를 피하도록 수정됐습니다. 업로드/검색/공지 등 서버 기능에는 인터넷 연결 및 유효한 기기 등록이 필요합니다.
- '전체방 전달'은 **V6 서버 수신함** 전달입니다. 원본 ChatGPT 대화창 자동 입력이 아닙니다.
- Google Drive의 파일은 Android 시스템 파일 선택기에서 직접 골라 업로드할 수 있으나, Drive 전체 자동 동기화는 아직 구현되지 않았습니다.

## 오류 화면 확인: HTML 코드가 그대로 보이는 경우
- 압축 파일 안의 `index.html` 또는 `v6_fallback.html`을 휴대전화 파일 앱에서 직접 탭하면 편집기에서 소스 코드가 보일 수 있습니다. 이는 V6 앱을 실행한 것이 아닙니다.
- 반드시 **압축 풀기 → AndroidIDE에서 프로젝트 폴더 열기 → Build APK → 생성된 APK 설치 → 홈 화면의 항행의자유 V6 아이콘 탭** 순서를 사용하세요.
- 이번 V6.0.1은 앱이 실행될 때 APK 안의 `v6_fallback.html`을 `text/html`로 렌더링하도록 수정했습니다. 휴대전화에서의 최종 시험은 설치 후 확인이 필요합니다.

## 1. AndroidIDE 빌드
1. ZIP을 **압축 풀기** 하세요. 결과 폴더 `V6_AndroidIDE_Project`가 나옵니다.
2. AndroidIDE를 실행하고 **Open Project(프로젝트 열기)**에서 이 폴더를 선택하세요.
3. 첫 실행 시 Gradle/Android SDK 구성요소를 다운로드할 수 있으므로 인터넷을 연결하세요.
4. 필요 버전: **JDK 17 / Android Gradle Plugin 8.7.3 / Gradle 8.10.2 / compileSdk 35 / minSdk 24**.
5. 프로젝트 동기화 후 `:app:assembleDebug` (Build APK 또는 debug 빌드)를 실행하세요.
6. 결과 예시: `app/build/outputs/apk/debug/app-debug.apk`.
7. 이 APK를 설치합니다. 앱 이름은 **항행의자유 V6**입니다.

## 2. 이후 업데이트 설치 조건 — 가장 중요
- 앱 식별자(applicationId)는 **`kr.hanghae.v6.centralcontrol`**로 고정합니다. 이 값을 바꾸지 마세요.
- 최초 설치가 AndroidIDE 빌드 APK라면, 다음 업데이트도 **같은 AndroidIDE의 같은 debug.keystore(서명키)**를 사용해야 기존 V6 위에 설치할 수 있습니다.
- AndroidIDE를 삭제하거나 휴대전화를 바꿀 경우 서명키가 바뀔 수 있습니다. **첫 빌드에 사용한 `~/.android/debug.keystore`를 안전하게 별도 백업하세요.** 비밀번호나 키 파일을 채팅/공개 저장소에 올리지 마세요.
- 신규 업데이트 프로젝트의 `app/build.gradle`에서 `versionCode` 값을 기존 값보다 증가시켜야 합니다. 이전 첫 버전은 **600001 / V6.0.0**, 이번 화면 오류 수정 버전은 **600002 / V6.0.1**입니다. 그 다음 업데이트는 **600003 / V6.0.2**처럼 증가시킵니다.
- 이후 업데이트 순서: **새 ZIP 압축 풀기 → 기존 서명키가 유지된 AndroidIDE에서 빌드 → 새 APK 설치(기존 V6 삭제하지 않음)**.
- GitHub Actions에서 따로 서명된 V6 APK가 이미 설치돼 있으면 AndroidIDE debug 키와 서명이 다를 수 있습니다. **그 APK 위로 바로 덮어쓸 수 있다고 보장할 수 없습니다.** 데이터/연결 상태를 백업하고 서명 일치 여부를 먼저 확인하세요.

## 3. 각 방 업로드 및 DB 누적
- V6 앱의 설정 → 기기 등록에서 기존 서버가 발급한 유효한 일회용 연결코드를 사용합니다.
- 1~5번방(또는 추가한 방) → 파일함 → 회차 입력 → 파일 선택 → 업로드
- 정상 등록 시 방 전용 폴더, V6 앱자료실, V6 누적DB에 같은 원본이 색인됩니다.
- 실구매 5조합은 정형 JSON (`document_type: V6_PURCHASE_5`, `stage: RESULT-BEFORE`)만 추출하고 **최종 승인 전**에는 후보 상태로 표시합니다.
- 파일별 최대 크기는 **10MB**입니다. V6 내부의 1회 업로드가 검증되기 전까지 작업 완료로 간주하지 마세요.

## 4. 자료 및 연결 범위 주의
- 서버 기존 V5 라이브러리에서 `IMPORTED`인 파일은 내려받을 수 있지만 `PENDING`은 메타데이터 목록만 존재할 수 있습니다.
- **V5 휴대전화 내부 누적 DB → V6 자동 이관**, **Drive 폴더 자동 양방향 연동**, **ChatGPT 개인 라이브러리 직접 자동 연동**은 현재 별도 구현 단계입니다.
- 서버가 점검 중에도 V6 홈 화면 자체는 앱에 내장돼 표시되며, 업로드·자료실·공지 등 서버 연결 기능은 이용할 수 없을 수 있습니다.

## 5. AndroidIDE 오류 발생 시 보내주실 것
- AndroidIDE **Build 출력의 첫 번째 오류** 화면
- 사용한 AndroidIDE 버전과 JDK/SDK 상태
- 압축 푼 뒤 프로젝트 폴더에서 `settings.gradle`, `gradlew`, `app`이 보이는지
- **개인정보, 서버 연결 토큰, 서명키 파일은 보내지 마세요.**

## 6. V6.0.2 상단 이동·업데이트 버튼
- **◀ 이전 / ⌂ 홈 / ⬆ 업데이트**가 V6의 홈, 각 담당방, 라이브러리, 누적DB 및 설정 화면에 표시됩니다.
- 안드로이드 자체 뒤로가기 또한 V6 내부 화면 이동을 우선 사용합니다.
- **⬆ 업데이트** → 최신 버전 확인 → 새 AndroidIDE ZIP 다운로드. 자동 APK 설치가 아닙니다.
- V6.0.2 프로젝트의 `versionCode`는 **600003**이며 패키지명은 기존 V6와 동일합니다.
- AndroidIDE 첫 설치 서명키가 동일해야 **앱 데이터 보존 업데이트 설치**가 가능하며, 서명키가 다르면 설치 실패할 수 있습니다. 최초 AndroidIDE debug.keystore를 반드시 안전하게 보존하세요.
- 새 ZIP을 받은 후: 압축 해제 → AndroidIDE에서 새 프로젝트 열기 → 빌드 → 기존 앱 위에 APK 설치(앱 삭제 금지).

## 7. V6.0.3 방제·링크 등록 오류 해결
- **설정 → 방 이름·링크**에서 직접 텍스트 입력 후 `방제 저장` 또는 `링크 저장`을 누릅니다.
- 인증키 없이 방제 변경, ChatGPT 원본 대화방 링크 등록, 새 방 추가를 **현재 휴대전화에 저장**할 수 있습니다.
- ChatGPT 일반방 `/c/…` 및 프로젝트 대화방 `/g/.../c/...` 주소를 허용합니다. URL 저장은 원본방 자동 메시지 전달을 뜻하지 않습니다.
- 추가 방은 서버 기기 등록 전에는 휴대전화 전용입니다. 서버 업로드·공지 전송은 유효한 기기 인증과 `방제·추가 방을 서버에 동기화`가 필요합니다.
- **1회용 연결코드**는 기존 V5/V6 서버 관리자가 발급하는 기기 등록 코드입니다. 사용자 임의의 문구를 입력하는 비밀번호가 아닙니다. 코드·서버 토큰을 외부로 공개하거나 채팅에 붙이지 마세요.
- 이번 버전: **V6.0.3 / versionCode 600004**. 기존 V6 설치 APK와 서명키가 동일해야 덮어쓰기 업데이트가 가능합니다.

## 8. V6.0.4 기기 연결 실패 대응 + 1246회 신서
- **설정 → 기기 연결 상태 확인**을 먼저 누르세요. 서버에서 이미 등록된 기기의 토큰이 이 앱에 있으면 새 코드는 필요 없습니다.
- 1회용 코드는 서버 사용 처리 후 재사용할 수 없습니다. 기존 코드가 실패했다면 계속 반복하지 말고 서버 저장 토큰 상태를 확인해야 합니다.
- 토큰이 없거나 유효하지 않을 때만 새로 발급된 인증코드를 등록하세요. 등록 버튼 중복 누름 방지, 토큰 저장 검증, 응답 오류 표시가 추가됐습니다.
- **1246회차 신서 원문**을 V6 자료실/누적DB의 미해석 참고자료로 표시합니다. 번호 조합이나 실구매 승인을 임의로 생성하지 않습니다.
- 버전: **V6.0.4 / versionCode 600005**. 동일한 AndroidIDE 서명키로 빌드하여 기존 V6 위에 설치하세요.

## 9. V6.0.5 홈으로 이동·메뉴 닫힘 개선
- 왼쪽 메뉴의 `🏠 홈으로`를 누르면 기존 V6 홈 화면(전체방·1~5번방)을 그대로 보여주며 메뉴는 즉시 닫힙니다.
- 방·자료실·누적DB·실구매용·설정·업데이트 등 어느 메뉴든 누르면 왼쪽 메뉴가 자동으로 닫힙니다.
- 메뉴가 열려 있을 때 휴대전화 뒤로 가기를 누르면 다른 화면으로 이동하지 않고 메뉴부터 닫힙니다.
- 이번 버전은 **V6.0.5 / versionCode 600006**입니다. 동일한 AndroidIDE 서명키로 기존 V6 위에 업데이트 설치하세요.

## 10. V6.0.6 앱 내부 화면 업데이트
- 이번 V6.0.6의 설치용 Android APK에는 HTTPS 서버에서 새로운 V6 화면을 받아 앱 내부에서 즉시 표시하는 기능이 포함됩니다. 홈·방·메뉴·서버 화면의 변경만 해당하며, 권한 및 Android 네이티브 기능 추가는 APK가 필요합니다.
- V6의 `⬆ 업데이트` → `⚡ 지금 앱 안에서 화면 업데이트`를 누르세요. 새 버전이 있으면 화면을 교체하고 앱의 내부 저장 공간에 보관해 다음 실행에도 사용합니다.
- 서버가 잘못된 HTML이나 오류를 보내면 검증에 실패하므로 기존 내장 화면을 유지합니다. 인증 토큰 등 앱 데이터는 삭제하지 않습니다.
- **최초 한번 이 기능을 포함한 V6 APK로 업그레이드**해야 합니다. 과거 V6에서 화면 버튼만 서버로 고쳐도 앱 내부 파일은 바뀌지 않습니다.
- GitHub CI APK와 AndroidIDE debug APK는 서명키가 다를 수 있습니다. 기존 V6 설치 APK와 **서명키가 일치하지 않으면** 직접 APK 덮어쓰기는 실패합니다. 기존 앱을 삭제하지 마세요. 최초 AndroidIDE 디버그 서명키를 유지하는 경우 동일한 키로 빌드한 APK를 한 번 설치해야 합니다.
- 버전: **V6.0.6 / versionCode 600007**. 기존 `kr.hanghae.v6.centralcontrol` 앱 ID는 유지합니다.

## 11. V6.0.7 홈 종료 버튼과 기존 AndroidIDE 폴더 업데이트
- 홈 화면에서 기존 6개 방 아래에 **🚪 앱 종료** 버튼이 보입니다. 누르면 확인창이 뜨며, 확인할 때만 Android V6 Activity를 종료합니다.
- 기존 AndroidIDE에서 설치한 APK의 서명키를 보존하려면 기존 프로젝트 폴더를 그대로 사용하세요. 변경 대상은 `app/build.gradle`, `app/src/main/java/kr/hanghae/v6/centralcontrol/MainActivity.java`, `app/src/main/assets/v6_fallback.html`, 프로젝트 루트 `index.html` 4개 파일뿐입니다.
- `sh v6/update_existing_project.sh`를 프로젝트 루트에서 실행하면 현재 파일을 다른 폴더에 백업하고 네 파일을 HTTPS로 가져옵니다. 성공 후 AndroidIDE에서 Build APK를 실행하세요.
- 기존 설치된 앱을 삭제하지 말고 **동일한 AndroidIDE 및 기존 서명키**로 생성한 APK를 덮어쓰기 설치해야 앱 데이터와 방제가 보존됩니다. `versionCode`는 `600008`, `versionName`은 `V6.0.7`입니다.
- 앱 종료 버튼은 브라우저에서 실행되는 미리보기에서는 실제 앱을 종료할 수 없습니다. Android V6 APK에서만 작동합니다.
