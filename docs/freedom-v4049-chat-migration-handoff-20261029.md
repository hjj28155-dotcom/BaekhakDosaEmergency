## 선장님 최신 확정 지시
1. 비상용 20조합 앱: 해당 회차 원문이 있으면 **주분석 70%**, 제1~전회차 보유 전체 원문 **보조분석 30%**; 원문 없으면 지난 회차 전체 원문 분석 **100%**. 5조합씩 4묶음.
2. 화면 열람은 당회차 포함 5회(현재 1248회 기준 1244~1248회), DB-1 역대 원본은 삭제/축소하지 않음.
3. 사용자 실기기 제1244회 화면에서 제목/당첨번호/설명 영역이 커서 **20조합이 한 화면에 모두 안 보이고 공 6개와 등수가 겹침**. V4.0.47에서 독립 CSS `v4047_compact.css`로 2×2 묶음, 4×5 조합 표시·레이아웃 간결화. 표 안의 ‘낙선/낙첨’ 문자열 제거, 0~2 적중 시 `0/6` 등만 표시. 상위 적중 시 1~5등 표시.
4. **원문분석→홈** 버튼 부재: V4.0.48에서 상단과 하단 홈 버튼을 추가했고, 닫기/이전이 원문분석으로 재진입하는 루프 수정. 기존 데이터·최초잠금 불변. V4.0.48 빌드·원본 서명·회귀 테스트 **통과**. 아직 휴대전화 실제 설치·화면은 확인 안 됨.
5. **최신 새 지시(아직 미완료):** **빵빠레(팡파레) + 축하 멘트 + 낙선 멘트**가 들어가야 함. 반복적인 목록 ‘낙선’은 제거 상태로 유지하되, **채점 결과 축하/낙선 오버레이와 음성은 반드시 동작**해야 함.
   - 기존 소스에 `showFanfare(round,best,wins)`, `showComfort(round,best)`, `playFanfareTone()`, `successVoiceText()`, `comfortVoiceText()`, `speakScoreFallback()`, `fanfareOverlay`, `comfortOverlay`가 이미 있음. 신규 20조합 `v4044ReviewRound` 및 `v4045GroupedScore` 화면에 연동이 **안 됨**. 기존 함수 재활용하여 채점 확정 결과에서 음악/멘트 재생, 스크린을 가리지 않는 오버레이 z-index, 반복 팝업 방지, 발표 전/원본 없는 경우 재생 금지 테스트 필요.
   - 과거 당첨번호 발표 후 생성된 `analysisResearch`는 ‘당첨 전 구매’로 오인시키지 말 것. 사후 연구 성적은 명확히 구분할 것.
6. **V4 신규설치 URL 및 V4 업데이트 URL은 별도 관리**; V4 설치 안내 `hanghae-freedom-distribution.html`과 Supabase `latest-apk` 등 기존 정식 경로를 임의로 변경/합치지 말 것. 공식 업데이트 공급은 여전히 구 V4.0.36, 설치 페이지는 별도 V4.0.41 Drive 링크가 있었음. 링크 승격은 실기기 검증/선장 승인 후.
