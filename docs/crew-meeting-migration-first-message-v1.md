## 적용 방식

- 공동회의 웹화면 상단 「새방 첫머리 인계문」 선택 → 역할 선택 → **양식 복사** → **새 ChatGPT 대화 열기** → **첫 메시지로 붙여넣어 전송** → 새 대화 URL을 기존 역할에 등록합니다.
- 원본 ChatGPT 방들을 자동으로 하나의 실시간 채팅으로 합치는 기능이 아닙니다.
- 같은 휴대전화의 공동회의 앱 저장소에는 역할별 최신방 주소와 이전방 목록이 보존됩니다. 앱 데이터 삭제·다른 브라우저 이동 시 동기화 제한이 있을 수 있습니다.
- 기준 문서는 정본으로 보관하되, 차기 회차·버전 숫자는 각 담당 작업대장의 **최신 실제 기록**을 재조회하여 결정합니다.
