**자료 건강성**: DB-1 1~1247회 1247건, 원문 각 6줄 확인, DB1 상태 PASS, 12436개 꿈사전 항목, 1~45 번호 자료. `scoreRaw`가 전 회차 OK를 반환(맞힌다는 의미 아님). 평균 표면일치 약 21.69항목/원문.

**실제 엔진 경로** (`index.html`의 `v4045AutoAnalyze20`):
1. 전회차 이하의 모든 RAW6를 `FREEDOM_REF_V4043.scoreRaw`로 분석.
2. `scoreRaw`는 합친 6문장 안에 사전 단어가 `text.includes(term)`로 존재하면 1~2.25점을 누적; 문장별 의미/방향 해독이나 부분문자열 오탐 방지 없음.
3. 평생 누적점수 최대값 정규화. 당회차 원문이 없으면 역사점수 100%, 있으면 당회차 70%/역사 30% (가중치 성능 근거 미확인).
4. 상위 **12개 숫자만** `pool`로 택한 뒤 `v123Auto20FromUniverse(pool,target,20)`로 그 안에서 6개를 결정론적 PRNG로 섞어 20조합 생성.
5. 따라서 1~45 중 **33개 번호는 해당 회차의 모든 조합에서 완전 제외**. 20조합이 총 12개 번호만 재사용하므로 조합 간 상관/편중이 큼.

**실제 최근 4개 공식 회차 재현**: `1244~1247`, 번들에 고정된 공식 당첨번호만 *생성 이후* 채점, 결과 점수는 생성 입력에 사용하지 않음.

| 대상 | 당회차 RAW 미사용: 후보 12수 중 당첨번호 개수 / 최고 적중 | 당회차 RAW 사용(70/30): 후보 12수 중 당첨번호 개수 / 최고 적중 |
|---|---|---|
| 1244 | 1 / 1개 | 0 / 0개 |
| 1245 | 1 / 1개 | 1 / 1개 |
| 1246 | 1 / 1개 | 1 / 1개 |
| 1247 | 0 / 0개 | 1 / 1개 |

- 이 4회차에서 두 방식 모두 **3개 이상 적중한 조합 0건**.
- **당회차 RAW 미사용 방식의 상위 12번호가 1244·1245·1246·1247·1248 전부 동일:** `10,7,40,20,6,30,12,16,9,5,3,1`. `1248`은 당첨번호 발표 여부와 무관하게 **후보 12수의 경직성 진단**에만 사용함.
- 당회차 RAW 사용 방식은 후보 일부가 변하나 **10/20/40/7 등 누적 상위 숫자가 자주 남음**.
- 주의: 일부 과거 RAW의 사후 수정·실제 최초분석 시점 증명은 별도임. 4회차의 결과는 **실제 성능을 확정할 수 있을 정도로 큰 독립 표본이 아님**. 미래 수익/적중 향상 보장 없음.

**분산형 비교 실험**: NumPy 난수 `seed=42`, 무작위 6/45 추첨 100000회, 각 전략 20장 고정. 비교군은 1~45 중 매 조합 임의 6개, 20장 중 실제 사용 번호 43개. **모델 예측력 비교가 아니라 조합 분산의 수학적 효과**.
- 현재 12수 집중 20조합: 5등 이상(3개 이상 일치) 조합이 **한 장이라도 있는 모의 추첨 비율 16.35%**.
- 45수 분산 비교 20조합: **39.47%**.
- 회차당 평균 3개 이상 일치 **조합수**는 각각 약 0.479 vs 0.479로 비슷하나, 집중형은 여러 장의 당락이 함께 움직여 '적중 회차수'가 떨어지고 변동성이 커지는 게 주원인.
- 위 수치는 1개 임의로 고정한 분산 비교군과 시뮬레이션으로 얻은 추정치. 예측력 또는 기대수익 개선 증거로 호도 금지.

**진단**: DB-1 파일 결손이나 20조합 생성 실패는 확인되지 않음. **최고 12수 반복 집중 + 무증빙 원문·꿈사전 출처점수 누적 + PRNG 섞기 구조**의 품질한계는 실물 코드와 재현에서 확인됨. 이는 **예측성능 검증되지 않은 연구용 점수**이므로 “1247회분 원문 분석을 했으니 더 잘 맞는다”는 가정은 입증되지 않음.
