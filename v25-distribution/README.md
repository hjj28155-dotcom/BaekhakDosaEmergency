# V25 공개 APK 배포 전용 준비 영역

이 영역은 **기존 백학도사/V4 배포를 변경하지 않고** V25 테스트 배포를 별도 관리하기 위한 임시 준비 브랜치입니다.

- 소스와 DB-1 전체 원문 및 통제관 엔진 내부 데이터는 GitHub 비공개 저장소 `hjj28155-dotcom/BaekhakCrownAndroid`의 `v25-isolated-build`에만 유지합니다.
- 공개 저장소: `hjj28155-dotcom/BaekhakDosaEmergency` (기존 프로젝트의 공개 릴리스 저장소를 **임시로 공유**). 이것은 별도 신규 저장소가 **아닙니다**.
- 이 브랜치 추가는 기존 `main`과 기존 V4/V3 APK·업데이트 파일을 변경하지 않습니다.
- APK 실물 빌드 성공·서명·설치 검증 전에는 V25 Releases 또는 설치 링크를 생성하지 않습니다.
- V25 릴리스 태그는 `v25.X.Y`만 사용하고, APK 이름은 `V25_....apk` 형식으로 분리합니다.
- 업데이트 앱은 V25 릴리스만 검색합니다. GitHub에 최신 V4 릴리스가 있어도 V25 업데이트로 안내하지 않습니다.

## 검증 게이트
1. 비공개 V25 Android 코드 GitHub Actions 디버그 APK 빌드 성공 확인
2. APK 패키지명·버전·서명 식별자 확인, 원문 HTML과 APK 내 HTML 일치 확인
3. 홈 '원본챗방'과 '업데이트 확인' 버튼, 수동 구간조회, 통제관 엔진 5조합, JSON/PNG 저장 확인
4. 필요 시 공개 테스트용 APK를 `v25.x.y` 태그의 별도 GitHub Releases 자산으로 배포
5. 기존 앱 설치자의 정식 업데이트로 안내하려면 기존 패키지명/서명 호환성을 먼저 별도 검증
