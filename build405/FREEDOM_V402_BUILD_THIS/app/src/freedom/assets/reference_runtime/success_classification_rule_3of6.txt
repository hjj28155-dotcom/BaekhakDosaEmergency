[성공사례 최소기준]
성공사례는 최종조합 최고 본번호 적중 3/6부터 시작한다.

분류:
- 3/6 성공사례 → 폴더 3_6
- 4/6 성공사례 → 폴더 4_6
- 5/6 성공사례 → 폴더 5_6
- 6/6 성공사례 → 폴더 6_6

0/6, 1/6, 2/6은 성공사례 폴더에 넣지 않는다.
실패·학습사례 또는 일반 결과후 복기로 분류한다.

[채점 원칙]
성공등급은 '최종조합 최고 본번호 적중' 기준으로 표기한다.
후보합집합 포착, 정확위치 적중, 보너스 포착은 별도 항목으로 기록하며
성공등급과 혼용하지 않는다.

[원본 보호]
결과전 잠금본은 수정하지 않는다.
성공사례 파일은 결과후 별도 복기본을 해당 등급 폴더에 저장한다.

※ Library 경로에서 '/'는 폴더 구분자로 사용되므로 실제 하위폴더명은
3_6, 4_6, 5_6, 6_6으로 생성한다.
