# 항행의자유 이동아이콘 — 새 프로젝트 V1.0.84

이 폴더는 과거 프로젝트와 별개로 처음부터 작성한 Android 소스입니다.

기능: 밤바다 색상 UI, 2열 4행 메뉴, 항행의자유 링크, MP3/MP4 선택 및 앱 전용 복사 보관, FM/AM/유튜브/TV 연결, 설정, 닻 플로팅 버튼, 업데이트·종료.

GitHub Actions `MoveIcon Fresh build` 워크플로가 APK와 소스 ZIP을 빌드 아티팩트로 출력합니다.

새 packageId `kr.hanghae.moveicon.fresh` — 기존 앱을 덮어쓰지 않는 별도의 신규 앱입니다. 기존 자료는 삭제하지 않습니다. 설치와 기능은 실기기 미검증입니다.
