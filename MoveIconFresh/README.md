# 항행의자유 이동아이콘 — 완전 신규 제작 V1.0.84

## 동그란 이동아이콘 중심
- 앱 시작 시 시스템 허용을 받은 뒤 다른 앱 위에 작은 **원형 닻(⚓)** 하나 표시
- 닻을 짧게 누르면 투명한 310dp 영역 안에 **8개 원형 버튼 메뉴** 펼침 (항행의자유, MP3, MP4, FM, AM, 유튜브, 실시간TV, 설정)
- 닻을 다시 누르면 메뉴만 사라지고 닻은 유지
- 닻 끌어 이동 및 좌표 저장, 다른 앱 위에 계속 표시
- 별도의 큰 전체화면 홈 메뉴 없음 (파일 관리 등은 작은 도구 창 사용)

## 내 폴더에서 불러오고 앱 안에 저장
- **내 음악/뮤비 폴더**는 Android 폴더 선택 창에서 직접 선택합니다.
- 원본을 삭제하지 않고 **앱 내부 files/보관함/MP3**, **files/보관함/MP4** 폴더로 복사합니다.
- 원본 하위 폴더 구조를 유지합니다.
- 앱 도구 창에서 MP3/MP4 보관함 탐색 및 재생합니다.
- 사용자 파일은 외부 다운로드 폴더로 자동 이동하지 않습니다.

## 바로가기
- 앱 또는 웹 링크 아이콘 추가·이름 변경·웹 주소 편집·삭제
- 길게 누르고 끌면 아이콘 이동, 위치 로컬 저장
- 삭제는 바로가기만 삭제하며 대상 앱/파일은 변경하지 않음

## 빌드·주의사항
- 별도 신규 앱 applicationId: `kr.hanghae.moveicon.fresh`.
- GitHub Actions: `.github/workflows/moveicon-fresh.yml`.
- GitHub 빌드에서 **APK + SOURCE ZIP**을 하나의 아티팩트로 생성
- 기존 이동아이콘을 삭제하거나 덮어쓰지 않음.
- 신규 앱이므로 기존 앱의 비공개 보관함 파일을 자동으로 가져오지는 않습니다.
- 실제 휴대전화 동작, 권한, 재생 및 오버레이 배치 검증은 별도로 필요합니다.
- 디자인 미리보기 이미지는 컨셉 시안이고, 현재 동작 화면과 픽셀 단위 동일하지 않습니다.
